# Roadmap

## Etapa 1: MVP y validación

- Base de clientes, carrito y checkout.
- Negocios demo.
- Pedidos con estado.
- Calculadora de rentabilidad.
- Pruebas locales con datos reales simulados.

## Etapa 2: Mejoras del cliente

- Cuenta y sesión.
- Direcciones guardadas.
- Historial de pedidos.
- Promociones.

## Etapa 3: Negocios

- Panel del negocio.
- Productos y precios.
- Pedido aceptado/rechazado.
- Ventas y comisiones.

## Etapa 4: Repartidores

- Registro.
- Disponibilidad.
- Pedidos activos.
- Estado de entrega.

## Etapa 5: Administración

- KPIs.
- Rentabilidad.
- Tarifas y zonas.
- Gestión de incidencias.
