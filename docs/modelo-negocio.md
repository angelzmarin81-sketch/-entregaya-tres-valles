# Modelo de negocio

## Visión

EntregaYa debe operar como plataforma local de pedidos y entregas para Tres Valles, con foco en negocios pequeños y servicio económico.

## Propuesta de valor

- Un cliente puede pedir desde varios negocios en una misma plataforma.
- Un negocio recibe pedidos sin pagar una infraestructura compleja.
- Un repartidor puede aceptar entregas con flujo simple.
- La operación se diseña para una zona geográfica pequeña.

## Criterios de negocio

1. El cliente debe pedir rápido.
2. El negocio debe aceptar pedidos sin fricción.
3. El repartidor debe recibir entregas simples.
4. La plataforma debe operar con pocos recursos.
5. La rentabilidad debe validarse antes de escalar.

## Fases

### Fase 1: MVP local
- 3 a 8 negocios piloto.
- 1 a 3 repartidores.
- 1 a 2 categorías iniciales.
- Cobertura por zona.

### Fase 2: Validación comercial
- Más negocios.
- Zonas ampliadas.
- Ajuste de comisiones y tarifas.

### Fase 3: Plataforma real
- Autenticación real.
- Pagos reales.
- Gestión operativa completa.
